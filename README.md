# right-click-pinboard-post
Right-click context menu extension for Chrome to post pages and selected text to pinboard.in

Since Chrome moved to V3 of their manifest format, one of my most-used plugins stopped working. I wrote my own version to replace it. 

INSTALLATION:
1. Download the files
2. Turn on developer mode in Chrome's extensions
3. "Load Unpacked" extension
4. Select the folder or zip file with this project in it. 
5. Right-click on webpages or highlight text and right-click it and select "Post... to pinboard"
